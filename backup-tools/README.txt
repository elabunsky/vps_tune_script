backup.py создаёт проверенные копии moscow и fn в ~/web_archive/.
Нужен доступ root через настроенные SSH-алиасы. Оба сервера Ubuntu 24.04.
Бекап передаётся прямо на ноутбук, без временного архива на VPS.
SQLite сохраняется через Backup API, MySQL — через mysqldump.

restore.py запускается из папки с датой рядом с каталогами moscow и fn:
  python3 restore.py moscow
  python3 restore.py fn
Перед восстановлением проверяется SHA-256 и запрашивается подтверждение.
На другом IP необходима отдельная правка Nginx, VPN и DNS.
Сеть, SSH и текущие учётные записи не заменяются автоматически.
Это копии конфигураций и приложений, а не загрузочные образы дисков.
Полное восстановление на чистом VPS пока не тестировалось.

Архивы содержат секреты и должны храниться с ограниченным доступом.
В GitHub загружаются только зашифрованные части из archives/.
